# ⚡ Daily DSA Practice

A clean, structured space where I log my daily Data Structures & Algorithms solutions, track my progress, and build problem-solving consistency.

---

### 📌 Overview

This repository acts as my personal code laboratory for technical interview preparation. The goal is simple: solve at least **one problem every day**, move from brute-force to optimal solutions, and document the reasoning along the way.

---

### 🗺️ Roadmap & Topics Covered

- [ ] **Arrays & Hashing** — Two Pointers, Sliding Window, Prefix Sums
- [ ] **Strings** — Pattern Matching, Palindromes, Parsing
- [ ] **Linked Lists** — Traversal, Reversal, Fast & Slow Pointers
- [ ] **Stacks & Queues** — Monotonic Stack, Priority Queues
- [ ] **Trees & Graphs** — BFS/DFS, BST, Tries, Shortest Path
- [ ] **Dynamic Programming** — Memoization, Tabulation, Knapsack Pattern

---

### 💡 Notes & Best Practices

1. **Space & Time Complexity:** Every solution includes explicit Big-$O$ time and space analysis.
2. **Multiple Approaches:** Solutions start with a basic approach before demonstrating the optimized logic.
3. **Clean Code:** Focus on readable variable naming and standard code style rather than short hacks.
